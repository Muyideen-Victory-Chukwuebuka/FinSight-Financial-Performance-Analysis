# FinSight Financial Performance Analysis

## Project Overview

This project presents a financial performance analysis of FinSight Distribution & Consumer Products Ltd. using Microsoft Power BI.

The analysis covers the 2024 and 2025 financial years, focusing on revenue growth, profitability, operating expenses, and branch performance.

The objective was to investigate why the company's revenue increased significantly without a corresponding improvement in profitability.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modelling
- Microsoft Excel

## Dashboard Overview

The Power BI report contains four interactive pages:

1. **Executive Dashboard:** Key financial performance indicators and revenue trends.
2. **Profit & Loss Statement:** Detailed financial reporting across 2024 and 2025.
3. **Branch Analysis:** Branch-level revenue, profitability, and operating expenses.
4. **Financial Growth Analysis:** Year-over-Year and Month-over-Month comparisons.

## Key Findings

- Revenue increased by **52.63%** from 2024 to 2025.
- Operating expenses increased by **78.01%** over the same period.
- Operating profit remained negative, with losses worsening in 2025.
- Profit before tax declined from approximately **-₦691.10 million** in 2024 to **-₦1.38 billion** in 2025.

These findings highlight the need for stronger cost management and improved operational efficiency.
